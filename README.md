# PizzaTicketSystem

Simple implementation of a "Pizza Order&Ticket"-Webpage.

## Installation

Make sure [Docker](https://docs.docker.com/engine/install/) and [NodeJS](https://nodejs.org/en/download) are installed and running.

Navigate to the pizza-tracker folder and install the required node-modules.

```bash
cd pizza-tracker
npm install
```

## Start
Navigate back to the root folder and start the stack.
```bash
cd ..
docker-compose up
```
